Project Development Update

Completed Features

1. Patient Management
- Patient registration with MySQL database integration.
- View and search patient records.
- Edit and delete patient details.

2. Doctor Management
- Add new doctors.
- View registered doctors.
- Search doctors by ID, name and specialization.
- Edit doctor information.
- Delete doctors while protecting existing appointment records.

3. Login and Registration
- Patient account registration.
- Password hashing using Werkzeug.
- Patient login authentication.
- Flask session-based login.
- Initial patient account and database linking.

4. Patient Dashboard
- Created a patient dashboard interface.
- Added links for doctor viewing and appointment booking.

Work in Progress

5. Appointment Management
- Doctor-wise daily appointment capacity: 30 tokens.
- First-come, first-served token allocation.
- Automatic token assignment.
- Handling fully booked dates and alternative dates.

6. Role-Based Access Management
- Admin, Doctor and Patient roles.
- Separate dashboards.
- Role-based permissions and access restrictions.
